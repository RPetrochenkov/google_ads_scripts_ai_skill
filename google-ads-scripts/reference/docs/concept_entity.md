# Google Ads Entities

Google Ads entities are the various components of a Google Ads account that you can manage with scripts. This includes a wide range of items such as Accounts, Campaigns, Ad Groups, Ads, Keywords, Budgets, Labels, and Targeting settings. Essentially, any object within the Google Ads hierarchy that you can programmatically access and manipulate is considered an entity.

## Common Entities

*   **Account:** The top-level account object.
*   **Campaign:** Represents a campaign.
*   **AdGroup:** Represents an ad group.
*   **Ad:** Represents an ad.
*   **Keyword:** Represents a keyword.
*   **Budget:** Represents a budget.
*   **Label:** Represents a label.
*   **Targeting:** Represents various targeting criteria, such as locations and audiences.
