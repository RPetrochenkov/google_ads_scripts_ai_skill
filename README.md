# Google Ads Scripts Repository

This repository is the central hub for developing Google Ads Scripts, with a strong focus on supporting script creation within the Claude Code environment.

## Purpose

The primary goal of this repository is to provide a structured and version-controlled environment to support the script development process. While it may contain production-ready scripts, its main purpose is to facilitate the creation and testing of new scripts.

This repository:

*   **Provides a space for script development and experimentation.**
*   **Maintains a local documentation hub.** This is crucial for providing Claude Code with the necessary context to make correct, data-driven suggestions, rather than relying on general knowledge alone.
*   **Streamlines the script creation process** with the help of AI.

## How to Use

1.  **Download the repository** to your local machine.
2.  **Open a terminal and navigate to the root directory** of the project.
3.  **Run Claude Code** from this directory. It will automatically load the `CLAUDE.md` file, which provides the necessary context to understand the project structure, coding standards, and business logic.
4.  **Start writing scripts** with the assistance of Claude.
5.  **Save new scripts** created with Claude's assistance to the `src/scripts/automated/` directory.

## Contents

*   `src/docs/`: Contains a local, offline-first documentation resource for the Google Ads Scripts API, including code examples, style guides, and business context.
*   `src/scripts/`: Contains all the Google Ads scripts, with a dedicated `automated` subdirectory for scripts created with Claude's help.
